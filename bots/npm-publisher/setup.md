The npm CLI must be installed and working on this machine.

- Confirm npm is available with `npm --version`.
- Confirm Node is available with `node --version`.
- If npm is missing, install Node.js — which bundles npm — using whatever package manager suits this machine, then re-check both commands.

Do not log in to npm and do not configure any npm account or credentials during setup. The bot checks authentication itself at run time and guides the user through `npm login` if needed.
